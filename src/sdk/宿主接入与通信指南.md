## 🚀 2. 业务系统集成步骤

### 2.1 引入 SDK 与嵌入 iframe 节点

#### 方式 A：UMD 全局引入（传统 HTML / 纯 JS 项目）

```html
<!-- 1. 业务系统 index.html 引入 UMD SDK 脚本 -->
<script
  defer
  src="https://open-web.hnocc.com/canvas-editor/sdk/editor-client.umd.cjs"
></script>

<!-- 2. 嵌入 <iframe> 容器 -->
<div class="editor-container" style="width: 100%; height: 100vh;">
  <iframe
    id="canvas-editor-iframe"
    src="https://open-web.hnocc.com/canvas-editor/index.html"
    allowfullscreen="true"
    allow="fullscreen"
    sandbox="allow-scripts allow-same-origin allow-modals allow-popups allow-forms allow-downloads"
    style="width: 100%; height: 100%; border: none;"
  ></iframe>
</div>
```

#### 方式 B：ES Module 引入（现代前端工程 / `<script type="module">`）

```html
<div class="editor-container" style="width: 100%; height: 100vh;">
```

### 2.2 实例化 SDK 与 TypeScript 类型定义

```typescript
export interface IEditorClientOptions {
  /** iframe DOM 元素引用或 CSS 选择器 */
  iframe: HTMLIFrameElement | string

  /** 系统应用 ID / 业务系统标识 */
  appId?: string

  /** 编辑器配置 */
  config?: {
    /** 初始模式: 'edit' | 'print' | 'readonly' | 'preview_edit' */
    mode?: 'edit' | 'print' | 'readonly' | 'preview_edit' | string
    /** 导出文件名 (支持静态文本或函数动态返回) */
    exportFileName?: string | (() => string)
    /** 功能开关 */
    features?: {
      all?: boolean // 一键开启全部
      save?: boolean // 保存按钮 (默认 false)
      print?: boolean // 打印按钮 (默认 true)
      export?: boolean // 导出菜单 (默认 false)
      control?: boolean // 控件工具栏 (默认 false)
      asidePanel?: boolean // 右侧占位符面板 (默认 true)
      modeSwitch?: boolean // 模式切换 (默认 false)
      comment?: boolean // 批注 (默认 false)
      signature?: boolean // 电子签名 (默认 true)
      macro?: boolean // 宏 (默认 false)
    }
  }

  /** 获取文档模板 (支持 Promise 函数或直接传模板对象) */
  getTemplate:
    | (() => Promise<{ data: any; options: any; version: string }>)
    | { data: any; options: any; version: string }
  /** 获取业务填充数据 (支持 Promise 函数或直接传数据对象) */
  getData:
    | (() => Promise<Record<string, any>> | Record<string, any>)
    | Record<string, any>
  /** (可选) 覆写右侧占位符字典 (默认由编辑器根据 appId 自动拉取) */
  getComponents?:
    | (() =>
        | Promise<Array<{ groupName: string; children: any[] }>>
        | Array<{ groupName: string; children: any[] }>)
    | Array<{ groupName: string; children: any[] }>

  /** 保存回调 (必传，提供统一的 toast 消息提示工具) */
  onSave: (documentJson: any, toast: IToast) => Promise<void> | void
  /** 打印回调 (返回 false 可阻止原生打印) */
  onPrint?: () => Promise<boolean | void> | boolean | void
  /** 图片/签名上传 (接收 Base64，返回 OSS 图片 URL) */
  onUploadImage?: (base64: string) => Promise<string>
  /** 导出回调 */
  onExport?: (type: string) => Promise<void> | void
  /** 模式切换回调 */
  onModeChange?: (mode: string) => Promise<void> | void
}

// 实例化示例
const client = new EditorClient({
  iframe: '#canvas-editor-iframe',
  appId: 'c377fb213ad9703',
  config: {
    mode: 'edit',
    // 导出文件名称（支持传入固定字符串或动态返回函数）
    exportFileName: '门急诊病历记录单',
    features: { save: true, export: true, asidePanel: true }
  },
  getTemplate: async () => (await axios.get('/api/template')).data,
  getData: async () => (await axios.get('/api/record')).data,
  onSave: async (data, toast) => {
    console.log('[宿主系统] 收到 Editor 提交保存 JSON:', data)
    const savePayload = {
      appId: 'c377fb213ad9703',
      reportData: JSON.stringify(data)
    }
    const closeLoading = toast.loading('文档保存中...')
    try {
      const res = await fetch('/system/report-template', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(savePayload)
      })
      const resData = await res.json().catch(() => null)
      if (!res.ok || (resData && Number(resData.code) !== 200)) {
        throw new Error(
          resData?.msg || resData?.message || `HTTP ${res.status}`
        )
      }
      toast.success('保存成功')
    } catch (err: any) {
      console.error('[宿主系统] 保存异常:', err)
      toast.error(err.message || '保存失败')
      throw err
    } finally {
      closeLoading()
    }
  },
  onUploadImage: async base64 =>
    (await axios.post('/api/upload', { base64 })).data.url
})
```

## 🛠️ 3. 公开的 API 方法

### 3.1 API 方法签名表 (`IEditorClient`)

| API 方法                    | TS 方法签名                                                                           | 说明                                                                                                                 |
| :-------------------------- | :------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------- |
| **`setControlValueList`**   | `setControlValueList(data?: Record<string, any> \| any[]): Promise<void>`             | **批量填充控件与明细表格**。缺省时自动使用 `getData()` 数据                                                          |
| **`getControlList`**        | `getControlList(): Promise<IControl[]>`                                               | **获取控件列表**。提取当前画布中所有表单/占位符控件核心配置结构                                                      |
| **`getMissingControlList`** | `getMissingControlList(data?: Record<string, any>): Promise<IControlDataAuditResult>` | **控件数据对齐与有效性审计**。返回包含 `missingControls`（未提供字段）和 `falsyControls`（除0和false外的假值）的对象 |
| **`getValue`**              | `getValue(): Promise<{ value: any; options: any } \| null>`                           | **获取全文 JSON 数据**。返回当前文档 `value` 与排版 `options`                                                        |
| **`exportPdf`**             | `exportPdf(): Promise<void>`                                                          | **触发导出 PDF**                                                                                                     |
| **`print`**                 | `print(): Promise<void>`                                                              | **触发打印面板**                                                                                                     |
| **`on`**                    | `on(event: string, listener: Function): void`                                         | **订阅编辑器事件**                                                                                                   |
| **`off`**                   | `off(event: string, listener: Function): void`                                        | **取消订阅编辑器事件**                                                                                               |
| **`destroy`**               | `destroy(): void`                                                                     | **销毁通信连接**                                                                                                     |

### 调用代码示例

```javascript
// 1. 触发填充业务数据 (缺省自动调用 getData)
await client.setControlValueList()

// 2. 检查数据与控件对齐与假值情况
const { missingControls, falsyControls } = await client.getMissingControlList()
if (missingControls.length > 0) {
  console.warn(
    '❌ 模板需要但下发数据中完全未提供的字段:',
    missingControls.map(c => c.conceptId)
  )
}
if (falsyControls.length > 0) {
  console.warn(
    '⚠️ 字段存在但值为假值/空值的控件:',
    falsyControls.map(c => c.conceptId)
  )
}

// 3. 手动下发增量更新数据
await client.setControlValueList({
  patient_name: '张三',
  patient_age: '30岁'
})

// 4. 获取文档内所有控件列表
const controlList = await client.getControlList()

// 5. 获取当前编辑器全文 JSON
const fullDoc = await client.getValue()

// 6. 触发导出 PDF
await client.exportPdf()

// 7. 页面销毁时解绑
client.destroy()
```

### 3.2 常用数据转换方法 (`EditorClient.transform`)

SDK 提供了静态工具方法 `EditorClient.transform`，用于在 `getData()` 传值前将后端异构数据快速转为编辑器标准格式：

| 转换方法                | 使用示例                                                                                                                                                                                                                                                                | 转换结果                                                                                                               | 说明                                                                                                          |
| :---------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------ |
| **`transform.list`**    | **① 按字段提取**：<br>`transform.list([{ name: '高血压' }], 'name')`<br>**② 自定义函数**：<br>`transform.list(list, (item, idx) => `${idx + 1}. ${item.name}`)`<br>**③ 大文本换行拆分**：<br>`transform.list('诊断一\n诊断二')`                                         | `['高血压']`<br><br>`['1. 高血压']`<br><br>`['诊断一', '诊断二']`                                                      | **分段文本列表** (`List.Text`)<br>支持按字段提取、自定义函数格式化序号、或将包含 `\n` 的大文本自动按行切分    |
| **`transform.images`**  | **① 按字段提取**：<br>`transform.images([{ url: '1.png' }], 'url')`<br>**② 自定义函数 (设宽高)**：<br>`transform.images(pics, item => ({ src: item.url, width: 120, height: 90 }))`<br>**③ 逗号字符串规整**：<br>`transform.images('1.png, 2.png')`                     | `[{ src: '1.png' }]`<br><br>`[{ src: '1.png', width: 120, height: 90 }]`<br><br>`[{ src: '1.png' }, { src: '2.png' }]` | **多图列表** (`List.Image`)<br>支持 URL 数组、对象数组提取、自定义排版尺寸、或逗号/分号分隔的图片字符串       |
| **`transform.options`** | **① 字段别名数组映射**：<br>`transform.options([{ title: '男', id: '1', active: '1' }], ['title', 'id', 'active'])`<br>**② 自定义函数组装**：<br>`transform.options(list, (item, index, list) => ({ label: item.title, code: item.id, checked: item.active === '1' }))` | `[{ label: '男', code: '1', checked: true }]`<br><br>`[{ label: '男', code: '1', checked: true }]`                     | **单选/多选组** (`Radio / Checkbox`)<br>支持别名映射或函数自定义映射，内置布尔安全引擎（解析 `'1'`/`'true'`） |

#### 使用示例代码

```javascript
// 在 getData 中结合 transform 快捷组装数据
const client = new EditorClient({
  iframe: '#canvas-editor-iframe',
  onSave: async data =>
    fetch('/system/report-template', {
      method: 'POST',
      body: JSON.stringify(data)
    }),
  getData: async () => {
    const raw = (await axios.get('/api/patient/1001')).data
    const { transform } = EditorClient

    return {
      // 1. 基础标量直接赋值
      'patient.name': raw.patientName,
      'patient.age': `${raw.age}岁`,

      // 2. 诊断多行列表：对象数组格式化为带序号字符串列表
      'diagnose.diagnosis_items': transform.list(
        raw.diagnoses,
        (item, index) => `${index + 1}. ${item.name}`
      ),

      // 3. 知情同意条款：将异构字段映射为多段 Checkbox
      'surgery.consent_clauses': transform.options(raw.clauses, [
        'title',
        'code',
        'isAgreed'
      ]),

      // 4. 影像多图：将逗号分隔的 OSS URL 串转为多图
      'exam.report_images': transform.images(raw.imageUrls, ['url'])
    }
  }
})
```

## 👂 4. 业务系统事件监听机制 (`on` / `off`)

业务系统可通过 `editorHost.on(eventName, handler)` 实时监听编辑器发送给宿主的各类事件。

### 支持监听的事件列表

| 事件名称 (`eventName`) | 触发时机                       | Callback 参数 (`payload`) 示例                 |
| :--------------------- | :----------------------------- | :--------------------------------------------- |
| **`contentChange`**    | 画布正文或元素发生变动时触发   | `{ wordCount: 128 }` (全文字数)                |
| **`modeChange`**       | 编辑器模式切换时触发           | `'edit'` \| `'readonly'` \| `'preview_edit'`   |
| **`controlChange`**    | 表单控件值改变或聚焦改变时触发 | `{ conceptId: 'patient_name', value: '李四' }` |
| **`pageScaleChange`**  | 页面缩放比例调整时触发         | `{ scale: 1.25 }` (缩放倍率)                   |

### 监听代码示例

```javascript
// 监听文档内容修改与字数统计
const handleContentChange = data => console.log('当前字数:', data.wordCount)
editorHost.on('contentChange', handleContentChange)

// 监听模式切换
editorHost.on('modeChange', newMode => console.log('模式切换:', newMode))

// 监听表单控件值修改
editorHost.on('controlChange', field =>
  console.log('控件修改:', field.conceptId, field.value)
)

// 取消监听
editorHost.off('contentChange', handleContentChange)
```

### 5.4 图片控件与单元格多图数据格式规范

宿主系统通过 `getData()` 或 `setControlValueList(data)` 下发图片数据时，支持以下格式：

#### 1. 单图控件（如患者头像 `patient_avatar`）

```json
{
  "patient_avatar": "https://oss.company.com/avatar/zhangsan.png"
}
```

_注：支持在线 https 图片 URL 或 Base64 格式。_

#### 2. 表格单元格内多图 / 单图控件（如 `lab_item_chart` 或 `photos`）

宿主端在明细表格记录中，支持以下 3 种格式传递：

- **格式 A（推荐，URL 字符串数组）**：
  ```json
  {
    "lab_item_chart": [
      "https://oss.company.com/chart1.png",
      "https://oss.company.com/chart2.png"
    ]
  }
  ```
- **格式 B（对象数组）**：
  ```json
  {
    "lab_item_chart": [
      {
        "url": "https://oss.company.com/chart1.png",
        "width": 180,
        "height": 120
      },
      { "url": "https://oss.company.com/chart2.png" }
    ]
  }
  ```
- **格式 C（单张图片字符串）**：
  ```json
  {
    "lab_item_chart": "https://oss.company.com/chart1.png"
  }
  ```

#### 3. 占位符保留规则（无图片或空数据）

- 当字段值为 **`[]`（空数组）**、**`null`**、**`undefined`** 或 **`""`（空字符串）** 时，编辑器**不会解包**，画布上会自动保留并展示图片占位符（如 `【@示意图表】`）。
- 此时调用 `getControlList()`，将返回 `placeholder: "示意图表"` 与 `value: []`，便于宿主识别该项尚未填值。

## 6. 表格模板操作与高级 HTML 语法规范

Canvas Editor 支持通过声明式 **HTML Table 模板**快速构建结构化病历与报告表格。表格内完整支持行级循环、单元格内局部循环、各类表单控件（复选框、单选框、图片、列表等）以及高级指令（合并同类项、条件显隐）。

> [!TIP]
> **排版书写建议**：
>
> - 模板中的普通文本与占位符建议紧凑书写，避免多余的深层缩进空格与空行；
> - 占位符统一使用双花括号语法 `{{ fieldKey }}` 或 `{{ item.fieldName }}`。

---

### 6.1 表格循环（行级循环 vs 单元格内循环）

#### 1. 行级循环（`<tr>` 循环：适用于明细清单、动态数据列表）

在 `<tr>` 上声明 `loop="item in 数据路径"`，根据数组长度动态复制整行：

```html
<table border="1" width="100%">
  <thead>
    <tr>
      <th width="15%">序号</th>
      <th width="45%">检查项目</th>
      <th width="20%">标准分</th>
      <th width="20%">实际得分</th>
    </tr>
  </thead>
  <tbody>
    <!-- 循环行：自动按 items 数组展开多行 -->
    <tr loop="item in scoreSheet.items">
      <td align="center">{{ item.index }}</td>
      <td>{{ item.itemName }}</td>
      <td align="center">{{ item.maxScore }}</td>
      <td align="center">{{ item.actualScore }}</td>
    </tr>
    <!-- 表尾合计行（不加 loop，保持单行） -->
    <tr>
      <td colspan="2" align="center"><b>合 计</b></td>
      <td align="center">{{ scoreSheet.totalMax }}</td>
      <td align="center">{{ scoreSheet.totalActual }}</td>
    </tr>
  </tbody>
</table>
```

#### 2. 单元格内块级循环（`<div>` 循环：每项独占一行，自动换行）

在单元格内部使用 `div` 声明 `loop`，每一条记录会自动换行排列：

```html
<table border="1" width="100%">
  <tr>
    <td width="20%" align="center">风险评估明细</td>
    <td width="80%">
      <!-- 块级循环：展开后每条数据独占一行 -->
      <div loop="rule in riskRuleList">
        {{ rule.riskLevelName }}：{{ rule.desc }}
      </div>
    </td>
  </tr>
</table>
```

#### 3. 单元格内行内循环（`<span>` 循环：全部项并排在同一行）

在单元格内部使用 `span` 声明 `loop`，多条数据并排在同一行内展示：

```html
<table border="1" width="100%">
  <tr>
    <td width="20%" align="center">关联标签</td>
    <td width="80%">
      <!-- 行内循环：多项以空格自然间隔，并排在同一行 -->
      <span loop="tag in tagList"> [{{ tag.name }}] </span>
    </td>
  </tr>
</table>
```

#### 4. 复合分组级联循环（`<tbody>` 大标题 + 子明细行）

外层按大类分组，内层按组内项目展开明细：

```html
<table border="1" width="100%">
  <!-- 外层大标题分组循环 -->
  <tbody loop="group in reportData.groups">
    <tr>
      <td colspan="3" bgcolor="#F2F4F8"><b>■ {{ group.title }}</b></td>
    </tr>
    <!-- 组内明细循环 -->
    <tr loop="item in group.items">
      <td>{{ item.name }}</td>
      <td>{{ item.result }}</td>
      <td>{{ item.reference }}</td>
    </tr>
  </tbody>
</table>
```

### 6.2 表格内插入复选框（Checkbox）与单选框（Radio）

#### 1. 结合循环使用（数据驱动勾选状态）

在循环模板中直接放置 `<input type="checkbox" />` 或 `<input type="radio" />`，展开时引擎会**自动读取**数据对象中的勾选字段（支持 `isChecked`、`checked`、`selected`、`isSelected`）：

```html
<table border="1" width="100%">
  <tr>
    <td width="20%" align="center">知情同意条款</td>
    <td width="80%">
      <!-- 复选框列表：只要 rule 带有 isChecked: true/false 即可自动回显勾选状态 -->
      <div loop="rule in consentList">
        <input type="checkbox" /> {{ rule.title }} - {{ rule.detail }}
      </div>
    </td>
  </tr>
  <tr>
    <td align="center">最终处置结论</td>
    <td>
      <!-- 单选框互斥列表 -->
      <div loop="opt in conclusionOptions">
        <input type="radio" /> {{ opt.label }}
      </div>
    </td>
  </tr>
</table>
```

> **宿主下发数据示例**：
>
> ```json
> {
>   "consentList": [
>     { "title": "条款一", "detail": "已告知手术风险", "isChecked": true },
>     { "title": "条款二", "detail": "已签署麻醉知情书", "isChecked": false }
>   ],
>   "conclusionOptions": [
>     { "label": "符合出院标准", "selected": true },
>     { "label": "需继续留观治疗", "selected": false }
>   ]
> }
> ```

#### 2. 固定静态复选框 / 单选框

```html
<td>
  <input type="checkbox" checked /> 阳性 (+) <input type="checkbox" /> 阴性 (-)
</td>
```

### 6.3 表格内插入图片与多图集合

#### 1. 动态图片字段占位符（支持单图 / 多图网格自动解包）

只要字段名包含 `img` / `image` / `photo` / `pic`，或在组件字典中定义为图片类型，下发图片 URL 数组时会自动渲染为图片：

```html
<table border="1" width="100%">
  <thead>
    <tr>
      <th>检查项目</th>
      <th>检查数值</th>
      <th>影像图谱 (多图)</th>
    </tr>
  </thead>
  <tbody>
    <tr loop="item in examRecords">
      <td>{{ item.examName }}</td>
      <td>{{ item.examValue }}</td>
      <!-- 传入图片 URL 数组时，自动在单元格内展开图片 -->
      <td>{{ item.photoList }}</td>
    </tr>
  </tbody>
</table>
```

> **数据下发格式**：
>
> ```json
> {
>   "examRecords": [
>     {
>       "examName": "B超肝胆扫查",
>       "examValue": "未见明显占位",
>       "photoList": [
>         "https://oss.example.com/b_ultrasound_1.png",
>         "https://oss.example.com/b_ultrasound_2.png"
>       ]
>     }
>   ]
> }
> ```

#### 2. 静态图片标签

直接使用标准 `<img>` 标签，支持设定宽高与样式：

```html
<div loop="rule in exam.report_images">
  <img src="{{ rule }}" width="80" height="80" />
</div>
```

### 6.4 表格内插入分段列表（List）与下拉选择（Select）

#### 1. 多行分段列表（List.Text）

对于临床诊断条目、分段病程记录等多行文本列表：

```html
    <td width="20%" align="center">临床初步诊断</td>
```

### 6.5 高级指令与布局特性

#### 1. 相邻相同数据垂直合并（`merge-same` 指令）

在 `<td>` 上添加 `merge-same` 属性，当明细循环展开后，相邻行中该列数据相同的内容将**自动纵向合并单元格**（`rowspan`），绝不错位：

```html
<table border="1" width="100%">
  <tr>
    <th>检验大类</th>
    <th>检测项目</th>
    <th>结果</th>
  </tr>
  <tr loop="item in lisData.items">
    <!-- 当连续多行的 category 相同（如均为"血常规"），自动垂直合并 -->
    <td merge-same align="center">{{ item.category }}</td>
    <td>{{ item.itemName }}</td>
    <td>{{ item.value }}</td>
  </tr>
</table>
```

#### 2. 条件渲染指令（`when` 指令）

在单元格或子元素上添加 `when="表达式"`，根据数据动态决定是否渲染：

```html
<div loop="item in scoreList">
  {{ item.name }}：{{ item.score }} 分
  <!-- 仅当分值低于 60 分时展示警告提示 -->
  <span when="item.score < 60" style="color: #e11d48; font-weight: bold;">
    [未达标]
  </span>
</div>
```

#### 3. 常用样式与属性支持列表

| 属性 / 样式         | 示例                                       | 说明                             |
| :------------------ | :----------------------------------------- | :------------------------------- |
| `colspan`           | `<td colspan="3">`                         | 横向合并单元格                   |
| `rowspan`           | `<td rowspan="2">`                         | 纵向合并单元格                   |
| `merge-same`        | `<td merge-same>`                          | 声明式自动纵向合并相同数据行     |
| `when`              | `<tr when="item.status == 1">`             | 表达式条件显隐控制               |
| `align` / `valign`  | `<td align="center" valign="middle">`      | 水平与垂直对齐                   |
| `bgcolor` / `style` | `<td bgcolor="#F5F7FA" style="color:red">` | 背景色、文字颜色与字号设置       |
| `pagingRepeat`      | `<thead>` 默认启用                         | 跨页时表头自动在续页顶部重复打印 |
